# Pokie

A fully autonomous job finding and applying agent — it hunts, you decide.

Frontend prototype built from the Pokie design handoff. Static HTML/CSS/JS,
self-hosted Poppins, hash-routed screens (`#welcome` → `#history`), live-run
simulation, persisted UI state. Backend contract in [API.md](API.md).

Live at **https://pokie.rachittiwari.com** (GitHub Pages, `gh-pages` branch).
